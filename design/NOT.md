# Stitch ekranları

Bu görüntüler yalnızca **görünüm referansıdır** (renk, font, bileşen yerleşimi).
Oyun içeriği (sahne metinleri, kanıtlar, seçenekler, sonuçlar) yalnızca
`scenarios/sabah-randevu.json` dosyasından gelir. Görüntülerdeki şu metinler
Stitch'in uydurduğu örneklerdir ve uygulamaya alınmaz:

- 03, 04, 05: arka plandaki "Ödeme Servisi", ölçüm kutuları ve log satırları
- 06: Postgres / API Gateway sahnesi (yalnızca terim balonu ve sayaç görünümü için referans)
- 04: tutor balonundaki örnek cevap (gerçek tutor spec §6 talimatına uyar)
